⚙️ What Each Step Does (LLM Pipeline)
StepWhat it doesStatus after
1 · Generate Asks Claude to write new R&W questions for the domain/difficulty you choose generated
2 · Agent Review Claude checks each question for correctness, answer key accuracy, and SAT style. Bad ones are rejected automatically reviewed
3 · Enrich Adds step-by-step explanations, trap analysis, and core concept enriched
4 · Validate You read each question and click Approve or Reject. Only approved questions appear in practice sessions approved
🎛️ Parameters Explained
ParameterWhat it controls
Section Math = algebra, geometry, data. R&W = reading & writing passages. Both = mix of both
Domain The specific topic area (e.g. Algebra, Geometry). Choose All to let the system pick the most under-covered domain automatically
Difficulty Easy = SAT levels 1–2, Medium = 3–5, Hard = 6–7. All uses the SAT distribution (more medium than hard)
Count How many questions to generate. Start with 5. Each question calls the AI so higher numbers take longer and cost more
Only re-review failed On the Review step — re-runs review only on questions that failed the last time. Use this to retry without re-reviewing everything
Include already-approved On the Enrich step — re-enriches questions that were previously approved. Use this to refresh explanations after a prompt update
🚀 Recommended Workflow
1
For Math questions: Use the SymPy Generate panel at the top. Pick skill, difficulty, pool (diagnostic for first batch) and count. Generation runs async — check back in ~60 seconds.
2
Go to SymPy Review to read each generated math question. Click Approve & Promote to push directly to the production questions table.
3
For R&W questions: Use the stats bar + step cards in the LLM section below. Use Run All Steps for the fastest workflow.
4
Watch the Job Log at the bottom. Lines in red are errors. A green ✓ DONE badge means success.
5
After LLM steps complete, go to LLM Review to approve R&W questions before they reach students.
