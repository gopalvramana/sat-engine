# Digital SAT — Complete Topic & Subtopic Reference

> **Purpose:** Canonical reference for all question and study-material authoring on Aptify.  
> Every topic here maps to the real Digital SAT as administered by College Board from 2024 onward.  
> Use this document to prioritise content creation, assign `skillKey` values, and plan curriculum coverage.

## Format Overview

| Section | Modules | Questions | Time |
|---|---|---|---|
| Reading & Writing | 2 × 32 min | 54 (27 per module) | 64 min |
| Math | 2 × 35 min | 44 (22 per module) | 70 min |
| **Total** | **4 modules** | **98** | **~2 hr 14 min** |

- **Adaptive:** Module 2 difficulty is determined by Module 1 performance.
- **Calculator:** Permitted on all Math questions; Desmos graphing calculator built in.
- **All R&W questions** are multiple-choice (4 options). Math is ~75% MCQ + ~25% student-produced response (grid-in).

## Math Domain 1: Algebra

**~13–15 questions (~35%) · Importance: HIGH**

The most foundational domain and the single largest source of questions. Fluency with linear equations and inequalities is essential for both the Algebra domain and as prerequisite knowledge for Advanced Math.

---

### 1.1 Linear Equations in One Variable

**Importance: HIGH**

| Subtopic | Notes |
|---|---|
| Solving multi-step linear equations | Variables on both sides, distribution, combining like terms |
| Fractional / decimal coefficients | e.g., `(2/3)x − 4 = 10` |
| Literal equations | Rearranging formulas to isolate a variable, e.g., solve `V = lwh` for `w` |
| No-solution / infinite-solutions cases | "For what value of k does the equation have no solution?" |
| Creating equations from word problems | Translating verbal descriptions into linear equations |
| Interpreting solutions in context | What does x = 5 represent in this scenario? |

**Typical question stems:**
- "What value of x satisfies the equation above?"
- "For what value of k does the equation have infinitely many solutions?"

---

### 1.2 Linear Equations in Two Variables

**Importance: HIGH**

| Subtopic | Notes |
|---|---|
| Slope-intercept form `y = mx + b` | Interpreting slope as rate of change, y-intercept as initial value |
| Standard form `ax + by = c` | Converting between forms |
| Point-slope form `y − y₁ = m(x − x₁)` | Writing equations from a point and slope |
| Computing slope from two points | `m = (y₂ − y₁) / (x₂ − x₁)` |
| Parallel lines (equal slopes) | Perpendicular lines (negative reciprocal slopes) |
| x-intercept and y-intercept | Identification and contextual interpretation |
| Writing equations from tables or graphs | — |

**Typical question stems:**
- "What is the slope of the line passing through (2, 3) and (5, 9)?"
- "In the equation y = 4x + 12, what does 12 represent?"

---

### 1.3 Linear Functions

**Importance: HIGH**

| Subtopic | Notes |
|---|---|

### 2.4 Nonlinear Functions

**Importance: HIGH (~6–8 questions across both modules)**

#### Quadratic Functions (~2–3 questions)

| Subtopic | Notes |
|---|---|
| Standard form `f(x) = ax² + bx + c` | y-intercept = c |
| Factored form `f(x) = a(x−r)(x−s)` | Zeros at r and s |

| Direction of opening | a > 0 → up (minimum); a < 0 → down (maximum) |

#### Exponential Functions (~2–3 questions)

| Subtopic | Notes |
|---|---|
| Growth: `f(x) = a(1+r)ˣ` | b > 1 |
| Decay: `f(x) = a(1−r)ˣ` | 0 < b < 1 |
| Initial value `a` in context | What does f(0) represent? |
| Percent change per period | Interpreting r |
| Exponential vs. linear modelling | Multiplicative vs. additive change |

#### Polynomial Functions (~1–2 questions)

| Subtopic | Notes |
|---|---|
| End behavior | Determined by leading term degree and sign |
| Zeros and multiplicity | Even = bounce; odd = cross |
| Sketching from factored form | Up to degree 3 on SAT |

#### Other Nonlinear Functions

| Subtopic | Notes |
|---|---|
| Rational functions | Vertical asymptotes (denominator = 0); horizontal asymptotes |
| Square root functions | Domain: x ≥ 0 |
| Absolute value functions | V-shape, vertex, transformations |
| Function transformations | `f(x)+k` vertical shift; `f(x−h)` horizontal shift; `−f(x)` reflection; `a·f(x)` stretch |
| Reading function graphs | Increasing/decreasing intervals, max/min, intercepts |

## Math: Additional Notes for Question Authoring

- **~25% of Math questions are student-produced response (SPR/grid-in).** Answers are numerical only; no negative answers. Fractions and decimals accepted.
- **No complex numbers.** Removed from the Digital SAT format.
- **No logarithms, no matrices** as explicit topics.
- **Standard deviation** is tested conceptually only — students are never asked to calculate SD from scratch.
- **Desmos graphing calculator** is built into the testing app; some questions are designed to be solved graphically.

**~8–12 questions (~20%) · Importance: MEDIUM–HIGH**

### 3.1 Transitions

**Importance: HIGH — ~5–6 questions (~10%)**

| Relationship | Example transitions |
|---|---|
| Contrast / concession | however, nevertheless, on the other hand, despite, although, yet, even so, in contrast |
| Addition / support | furthermore, in addition, moreover, also, additionally |
| Cause-effect | therefore, thus, as a result, consequently, because, since |
| Exemplification | for example, for instance, specifically, in particular |
| Sequence / time | first, then, next, finally, subsequently, meanwhile |
| Emphasis / clarification | indeed, in fact, that is, in other words |

**Typical question stem:** "Which choice completes the text with the most logical transition?"

**Strategy:** Identify the logical relationship between the two sentences; match it to the right transition category.

**Common traps:**
- Confusing "therefore" (logical consequence) with "furthermore" (addition)
- Choosing a contrast word when the relationship is cause-effect

---

**Importance: HIGH — ~5–6 questions (~10%)**

- Identifying which notes are relevant to the stated goal

## R&W Domain 4: Standard English Conventions

**~11–15 questions (~26%) · Importance: HIGH**

All questions are grammar/punctuation. Formulaic and highly learnable with targeted practice.

**Typical question stem for all questions in this domain:**  
"Which choice completes the text so that it conforms to the conventions of Standard English?"

---

### 4.1 Boundaries (Punctuation and Sentence Structure)

**Importance: VERY HIGH — ~5–6 questions (~10%)**

#### Connecting Independent Clauses

| Correct method | Example |
|---|---|
| Semicolon `;` | "She studied hard; she passed the exam." |
| Comma + FANBOYS | "She studied hard, so she passed." |
| Period / end punctuation | Two separate sentences |
| **ERROR: comma splice** | "She studied hard, she passed." ← incorrect |
| **ERROR: run-on / fused sentence** | "She studied hard she passed." ← incorrect |

#### Dependent Clauses and Phrases

| Subtopic | Rule |
|---|---|
| Introductory subordinate clause | Followed by a comma: "When he arrived, the party started." |
| Introductory participial phrase | Followed by a comma: "Walking to school, she noticed the flowers." |
| Non-restrictive (non-essential) element | Set off with commas or dashes; can be removed without changing meaning |
| Restrictive (essential) element | NO punctuation; removing it changes meaning |

#### Colons and Dashes

| Mark | Usage |
|---|---|
| Colon `:` | Introduces list, explanation, or example; must be preceded by a complete clause |
| Single dash `—` | Introduces explanation or list; more informal than colon |
| Paired dashes `— —` or paired commas | Set off non-essential information in the middle of a sentence |

#### No Punctuation Needed

- Between subject and verb
- Between verb and its direct object
- Between preposition and its complement
- Essential "that" relative clauses (no commas)

---

### 4.2 Form, Structure, and Sense (Grammar and Usage)

**Importance: VERY HIGH — ~7–8 questions (~14%)**

#### Subject-Verb Agreement

| Subtopic | Notes |
|---|---|
| Basic rule: singular subject → singular verb | — |
| Prepositional phrase between subject and verb | "The box of apples *is* heavy." — subject is "box" |
| Collective nouns | Usually singular: "The team *is* ready." |
| Indefinite pronouns (singular) | each, every, everyone, nobody, someone, anyone → singular verb |
| Indefinite pronouns (plural) | both, few, many, several → plural verb |
| Inverted sentence order | "There *are* many reasons..." |

#### Pronoun-Antecedent Agreement

| Subtopic | Notes |
|---|---|
| Number agreement | Pronoun must match singular/plural of antecedent |
| Singular indefinite pronoun antecedents | everyone, someone → use singular pronoun (their is now accepted for gender neutrality) |
| Pronoun case | Subjective (I, he, she, they, who), objective (me, him, her, them, whom), possessive (my, his, her, their) |
| Ambiguous pronoun reference | Avoid when two possible antecedents exist |

#### Verb Tense, Form, and Mood

| Subtopic | Notes |
|---|---|
| Consistent tense within a passage | — |
| Simple tenses: past, present, future | — |
| Perfect tenses | Past perfect (had done), present perfect (have done), future perfect (will have done) |
| Progressive tenses | Past progressive (was doing), present progressive (is doing) |
| Infinitive vs. gerund | e.g., "He decided *to leave*" vs. "He enjoys *leaving*" |
| Subjunctive mood | "If I *were*..."; "It is important that he *be*..." |
| Finite vs. nonfinite verbs | Participles as adjectives; gerunds as nouns |

#### Modifier Placement

| Subtopic | Notes |
|---|---|
| Dangling modifier | Introductory phrase must modify the grammatical subject of the main clause |
| Misplaced modifier | Adjective or adverb too far from the word it modifies |
| **Error example** | "Walking down the street, the trees looked beautiful." ← trees are not walking |

#### Noun Number and Possessives

| Subtopic | Notes |
|---|---|
| Singular possessive | `the student's book` |
| Plural possessive | `the students' books` |
| Irregular plurals | children's, women's, men's |
| `its` vs. `it's` | Possessive vs. contraction |
| `their` vs. `they're` vs. `there` | — |
| Noun as adjective | Generally no apostrophe: "a teachers union" |

## R&W: Additional Notes for Question Authoring

- **All R&W questions are MCQ with exactly 4 options.**
- **One question per passage.** No multi-question passage sets.
- **Passage sources:** Literature, History/Social Studies, Humanities, Science. Questions from all four skill domains appear in all passage content types.
- **Passage length:** 25–150 words. Paired-passage questions use two short texts.
- **Only one Cross-Text Connections question** appears per section (paired passage).
- **Rhetorical Synthesis questions** supply their own bullet-point notes — no reading passage required.
- **Questions appear in a roughly fixed order per module:** Words in Context → Text Structure & Purpose → Cross-Text Connections → Command of Evidence (Textual + Quantitative) → Central Ideas & Details → Inferences → Boundaries → Form, Structure & Sense → Transitions → Rhetorical Synthesis.
