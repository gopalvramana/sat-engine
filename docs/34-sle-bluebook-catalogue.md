## 4. Recommendations

### Add (medium priority)
- **`infinite_solutions_point` template (d3):** System has infinitely many solutions (second equation is a scalar multiple of the first). A free parameter r is introduced. Student is shown four candidate points expressed as algebraic expressions in r and must identify which lies on both lines for all real r. Anchored: pp.0010, 0016, 0052, 0078.

- **`unique_intersection_find_constant` template (d3):** System contains one unknown constant in a coefficient or term. Student is told the system has exactly one solution and is given one coordinate of that intersection point (e.g., x = 4 or y = 19). Student substitutes and back-solves for the constant. Anchored: pp.0062, 0065.

### Skip (too low volume)
- Graph → system identification (1 BB question): exotic, requires diagram reading in reverse
- Equation → graph matching (1 BB question): architecturally complex, low ROI
