## Domain: Problem Solving & Data Analysis

### RAT — Ratios, rates, proportional relationships, and units

**CB claim:** Solve problems using proportional relationships, ratios, rates, and units — including derived units and unit conversion.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Solve using proportional relationship between two quantities | 🔒 | Core type — appears across all SAT levels |
| Calculate or use a ratio or rate in context | 🔒 | Straightforward rate problem |
| Derived units from products (e.g., kWh) | 🔒 | SAT-level; e.g., density × volume = mass |
| Derived units from quotients (e.g., population per km²) | 🔒 | SAT-level |
| One-step unit conversion | 🔒 | All levels; e.g., cm → m |
| Multistep / multidimensional unit conversion | 🔒 | SAT + PSAT 10; e.g., km/h → m/s |
| Scale factor: one quantity changes by k → other changes by k | 🔒 | Proportional scaling in context |
| Apply proportional reasoning: scale drawings, science contexts | 🔒 | Broad contextual application |

**Estimated cognitive clusters (SAT-level):**
- T1: Rate / ratio in context (find value, compare rates)
- T2: Unit conversion (one-step and multistep)
- T3: Derived unit problems (density, speed, concentration)
- T4: Scale factor / proportional scaling
- T5: Multi-rate comparison or combined-rate word problem

### OVD — One-variable data: distributions and measures of center and spread

**CB claim:** Analyze and interpret numerical data distributions; calculate and compare mean, median, range, standard deviation; understand effect of outliers.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Analyze/interpret frequency table, histogram, dot plot, box plot | 🔒 | All levels; read and describe the distribution |
| Calculate mean, median, range for a dataset | 🔒 | All levels; procedural |
| Compare distributions with different standard deviations | 🔒 | SAT + PSAT 10 |
| Compare distributions with different means and same SD | 🔒 | SAT + PSAT 10 |
| Effect of outliers on mean and median | 🔒 | SAT + PSAT 10; direction of shift |
| Interpret spread / center in context | 🔒 | What does the median/mean represent? |

**Estimated cognitive clusters:**
- T1: Read value from distribution display (histogram/dot plot/box plot)
- T2: Calculate mean, median, range from table or list
- T3: Compare two distributions (center and/or spread)
- T4: Outlier effect — which measure changes, by how much
- T5: Interpret a statistical measure in real-world context

### TVD — Two-variable data: models and scatterplots

**CB claim:** Analyze and interpret scatterplots; fit linear, quadratic, and exponential models; compare linear and exponential growth; interpret graphs.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Analyze/interpret scatterplot (read values, describe trend) | 🔒 | All levels |
| Make predictions using a line/curve of best fit | 🔒 | SAT + PSAT 10 |
| Fit a linear model to scatterplot data | 🔒 | SAT + PSAT 10; identify slope/intercept of best-fit line |
| Fit a quadratic or exponential model to scatterplot data | 🔒 | SAT only; "which model best fits?" |
| Read and interpret a graph of two-variable relationship | 🔒 | All levels |
| Compare linear and exponential growth | 🔒 | SAT + PSAT 10; which grows faster? |

**Estimated cognitive clusters:**
- T1: Read value from scatterplot / line of best fit at a given x
- T2: Predict using best-fit line (interpolate or extrapolate)
- T3: Interpret slope or intercept of best-fit line in context
- T4: Choose best model type (linear vs. quadratic vs. exponential)
- T5: Compare linear vs. exponential growth (which is larger at x?)

### PRB — Probability and conditional probability

**CB claim:** Use one-way tables, two-way tables, and area models to find relative frequency, probability, and conditional probability.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Find probability from one-way frequency display | 🔒 | All levels |
| Find probability from two-way table | 🔒 | All levels; P(A and B), P(A or B) |
| Find conditional probability from two-way table | 🔒 | All levels; P(A | B) |
| Find probability from area model | 🔒 | All levels |
| Given probability, find unknown count in table | 🔒 | All levels; reverse direction |

**Estimated cognitive clusters:**
- T1: Simple probability from frequency table (P = part/whole)
- T2: Conditional probability from two-way table
- T3: Complement / "not" probability
- T4: Given P, find missing cell count in table
- T5: Area model probability (geometric probability)

### INF — Inference from sample statistics and margin of error

**CB claim:** Use sample statistics to estimate population parameters; interpret margin of error; understand sample size effect.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Use sample mean to estimate population mean | 🔒 | SAT + PSAT 10 |
| Use sample proportion to estimate population proportion | 🔒 | SAT + PSAT 10 |
| Interpret margin of error | 🔒 | SAT only |
| Larger sample size → smaller margin of error | 🔒 | SAT only; conceptual |

**Estimated cognitive clusters:**
- T1: Estimate population total from sample proportion (scale up)
- T2: Interpret margin of error (what range does it imply?)
- T3: Compare two survey designs — which gives smaller margin of error?
- T4: Infer population value from sample statistic in context

### EVL — Evaluating statistical claims: observational studies and experiments

**CB claim:** Evaluate statistical claims from studies; distinguish observational vs. experimental; assess causality and generalizability.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Identify which population results generalize to (random sample) | 🔒 | SAT only |
| Determine if evidence supports a causal relationship | 🔒 | SAT only; random assignment required for causality |
| Explain why random assignment supports causality | 🔒 | SAT only; conceptual |
| Identify issues with sampling methods | 🔒 | SAT only; biased sample → can't generalize |

**Estimated cognitive clusters:**
- T1: Generalizability — can the result be extended to a larger population?
- T2: Causality vs. association — is this an experiment or observational study?
- T3: Random assignment — why does it support a causal claim?
- T4: Sampling bias — which population does the result apply to?

## Domain: Geometry and Trigonometry

### ARA — Area and volume (maps to CB "Area and volume" SKT)

**CB claim:** Solve real-world and mathematical problems about area, perimeter, surface area, and volume; apply scale factor rules.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Area / perimeter of 2D geometric figures | 🔒 | All levels; triangle, rectangle, circle, composite |
| Surface area of 3D figures | 🔒 | All levels |
| Volume of 3D figures | 🔒 | All levels; cylinder, cone, sphere, prism |
| Select correct formula and calculate | 🔒 | Procedural fluency required |
| Scale factor k: lengths ×k, areas ×k², volumes ×k³ | 🔒 | SAT + PSAT 10 |

**Note:** `volume_3d.py` and `area_2d.py` both exist as separate skill files. CB bundles them as one SKT. Both need cataloguing.

**Estimated cognitive clusters:**
- T1: Find area or perimeter of standard 2D shape (given dimensions)
- T2: Find volume or surface area of standard 3D shape
- T3: Composite figure — combine/subtract areas
- T4: Scale factor — if dimensions change by k, how does area/volume change?
- T5: Reverse — given area/volume, find a missing dimension

### TRG — Right triangles and trigonometry

**CB claim:** Solve problems using Pythagorean theorem, special right triangles, right triangle trig (sin/cos/tan), complementary angle identity, radian measure, and unit circle.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Pythagorean theorem | 🔒 | All levels; find missing side |
| Special right triangles (30-60-90, 45-45-90) | 🔒 | SAT + PSAT 10 |
| Right triangle trig: sin, cos, tan | 🔒 | SAT + PSAT 10; SOH-CAH-TOA |
| Use similarity to calculate trig values | 🔒 | SAT only |
| sin/cos of complementary angles: sin θ = cos(90°−θ) | 🔒 | SAT only |
| Radian measure in unit circle problems | 🔒 | SAT only |

**Note:** `pythagorean.py` is a separate skill file (PYT). CB bundles PYT into the same SKT as TRG. Both need cataloguing together before template design.

**Estimated cognitive clusters:**
- T1: Find missing side using Pythagorean theorem
- T2: Find missing side/angle using sin/cos/tan in a right triangle
- T3: Special right triangle — find exact side length (30-60-90 or 45-45-90)
- T4: Complementary angle identity (sin θ = cos(90°−θ))
- T5: Unit circle — find sin/cos/tan for a given angle in radians or degrees

### CIR — Circles

**CB claim:** Use properties and theorems relating to circles (radii, diameters, tangents, arc lengths, sector areas); write and interpret circle equations; complete the square.

| CB SKT | Status | Notes |
|--------|--------|-------|
| Arc length from central angle | 🔒 | SAT only; arc = (θ/360) × 2πr |
| Sector area from central angle | 🔒 | SAT only; sector = (θ/360) × πr² |
| Properties: radius, diameter, tangent, chord | 🔒 | SAT only |
| Equation of circle: (x−h)²+(y−k)²=r² (standard form) | 🔒 | SAT only |
| How equation changes affect the graph (and vice versa) | 🔒 | SAT only; shift center, change radius |
| Complete the square to find center/radius from general form | 🔒 | SAT only; x²+y²+Dx+Ey+F=0 → standard form |
| Convert degrees ↔ radians | 🔒 | SAT only |
| Distance formula in circle problems | 🔒 | SAT only; e.g., find chord length |

**Estimated cognitive clusters:**
- T1: Arc length or sector area from central angle
- T2: Write equation of circle given center and radius
- T3: Read center and radius from standard-form equation
- T4: Complete the square to convert general form → standard form
- T5: Effect of changing h, k, or r on the circle graph
- T6: Tangent line properties (tangent ⊥ radius at point of tangency)
