### Narration example source policy (approved 2026-04-27)

| Source | Valid for narration examples? | Notes |
|--------|------------------------------|-------|
| `screenshots` (local Bluebook PDFs) | ✅ Always | Highest quality anchor |
| `Prepzy scan` (date + Q#) | ✅ Approved | Cognitive type confirmed by direct observation in a CB-style question bank; Prepzy's licensing status is unknown and irrelevant — copyright protects specific expression, not cognitive types or mathematical structures; write fresh numbers and scenarios, same structure |
| `framework` (CB Assessment Framework PDF, no question observed) | ⚠️ Requires Prepzy scan confirmation first | Must observe at least 1 real question of this type before writing narration examples |
| `synthetic` / `design` | ❌ Hard blocker | Never — cognitive type was not observed anywhere; do not implement |

**Rule:** Any gap whose cognitive type was directly observed in the Prepzy scan may use `Prepzy scan (YYYY-MM-DD, Q#)` as the Source column value in the narration coverage table. This is treated as equivalent to `screenshots` for gate purposes. The Prepzy scan confirms that the cognitive type *exists and has measurable frequency* in a large SAT-style question bank — that is the anchor, not the specific question text. Gaps that are framework-stated but not yet confirmed by observation must be scanned before narration examples are written.
